CAR SCORER — SAFARI WEB APP

Files:
- index.html
- apple-touch-icon.png

Recommended hosting: GitHub Pages.

After it is live:
1. Open the site in Safari on iPhone.
2. Tap Share.
3. Tap Add to Home Screen.
4. Turn on "Open as Web App".
5. Tap Add.

Scores are stored locally in Safari on that iPhone.
Google links open externally so you can return to the scorer without losing your place.
